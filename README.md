# Wortweg — немецкий от A0 до C1

Приложение для изучения немецкого: 3000 слов с переводом по уровням A0–C1, 45 тем грамматики с правилами и тестами,
90 текстов с тестами на понимание, интервальное повторение, письменные ответы, тренажёр артиклей, XP, цель дня и серия дней.

- Без сервера и без зависимостей: чистые HTML, CSS и JavaScript.
- PWA: ставится на телефон и компьютер, работает без интернета, обновляется автоматически.
- Прогресс хранится на устройстве (`localStorage`, ключи `ww-*`). Перенос между устройствами: Профиль → «Перенос прогресса».

## Установка на телефон

Откройте адрес сайта (GitHub Pages) и:

- **Android (Chrome):** меню ⋮ → «Установить приложение», или Профиль → «Установить».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».
- **Компьютер (Chrome, Edge):** значок установки в адресной строке.

## Структура

| Путь | Что там |
| --- | --- |
| `src/shell.html` | стили, разметка шапки и нижней панели |
| `src/app.js` | логика приложения: экраны, тесты, повторение, профиль |
| `src/pos.js` | определение частей речи |
| `src/data/*.js` | словарь по уровням, грамматика, тексты |
| `pwa/` | манифест, service worker, иконки |
| `build.sh` | собирает `index.html` (одна страница) |
| `build-pwa.sh` | собирает устанавливаемую версию в `dist/` |

## Сборка и деплой

```bash
./build-pwa.sh
```

Готовый сайт появляется в `dist/`. Локальный просмотр: `cd dist && python3 -m http.server`, затем http://localhost:8000.

Деплой: в репозитории **Settings → Pages → Source: GitHub Actions**. Каждый push в `main` запускает
`.github/workflows/deploy-pages.yml`, который собирает `dist/` и публикует его на `https://<user>.github.io/<repo>/`.
